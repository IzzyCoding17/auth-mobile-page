Login & Register Page (Flutter)

A mobile login and sign-up screen built with Flutter and Dart. a full purple login screen, and a white curved panel that slides up for sign-up.

Features
Animated transition between Login and Sign Up
Purple theme with a white curved form panel
Form validation (email format, minimum 6-character password, matching confirm password)
Show/hide password toggle
"Remember me" checkbox and "Forgot Password?" link on the login view
